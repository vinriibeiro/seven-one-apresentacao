## O que a apresentação mostra

1. **Seus dados protegidos:** camadas de proteção, vigia automático com alertas, plano de contingência com botão de emergência e o esquema completo risco × resposta.
2. **O que o Seven One tem:** os módulos e para que serve cada um.
3. **A jornada de uma venda**, do app do vendedor ao painel da gestão.
4. **Indicadores**, no sistema e no painel de BI.
5. **Proposta:** integração somente de leitura com a Claro, para receber as vendas da Seven sem digitar de novo.
6. **O que vem por aí** e como avaliar com um piloto.

## Sobre este repositório

Versão estática gerada a partir do projeto do sistema (`ferramentas/pages/gerar.mjs`). Contém só a parte visível no navegador e dados de demonstração: nenhum servidor, banco de dados, senha ou chave. O link do painel de Power BI abre um serviço externo, fora desta demonstração.
